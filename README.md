# Dozor

Дозор — розвідувальний обхід: подивитися, що є навкруги, у межах дозволеного.

Нативна macOS-обгортка над Nmap: профілі сканування, безпечний запуск, результати,
історія, порівняння та експорт. SwiftUI + AppKit, без Xcode-проєкту — збирається
через SwiftPM.

## Стан

MVP: профілі → запуск → результати → історія → експорт (JSON / CSV / XML / HTML)
→ порівняння запусків. Пропоновані діапазони з поточних мереж Mac, MAC-адреси
та імена знайдених хостів, масштаб тексту (⌘+ / ⌘− / ⌘0).
Локалізація: українська та англійська.

## Збірка

```bash
./Scripts/bundle.sh          # → build/Dozor.app (іконку згенерує сам)
swift Scripts/make-icon.swift  # перемалювати іконку окремо
swift run DozorKitTests       # тести ядра
DOZOR_LIVE=1 swift run DozorKitTests           # + реальний скан 127.0.0.1
DOZOR_DUMP_NETWORKS=1 swift run DozorKitTests  # показати мережі цього Mac
```

Потрібно: macOS 14+, Command Line Tools (Xcode не обов'язковий), `brew install nmap`.

## Архітектура

| Модуль | Призначення |
|---|---|
| `Sources/DozorKit` | Ядро без UI: валідація цілей, політика, запуск процесу, парсер XML, сховище, експорт, diff. Переноситься на інші платформи. |
| `Sources/Dozor` | SwiftUI-інтерфейс: сканування, результати, історія, профілі, налаштування, аудит. |

## Модель безпеки

* **Без оболонки.** `Process` + масив argv → `posix_spawn`. Жоден рядок користувача
  не потрапляє в shell; немає word-splitting, glob чи підстановок.
  Середовище дочірнього процесу фіксоване.
* **MAC і ім'я хоста.** Непривілейований скан (`-sT`) не бачить MAC — для ARP
  потрібні raw-сокети. Але скан щойно поговорив з кожним живим хостом сегмента,
  тож ARP-кеш ядра теплий: програма читає його одним `sysctl` (без трафіку, без
  root, без підпроцесу) і підставляє MAC, позначаючи джерело. Виробника бере з
  таблиці префіксів, що йде з Nmap; для локально адміністрованих (випадкових)
  адрес виробник не показується — збіг OUI там був би вигадкою. Імена хостів, які
  Nmap не розв'язав, довизначає системний резолвер: він бачить mDNS-імена `.local`,
  яких власний резолвер Nmap не бачить. Опитуються лише живі безіменні хости.
* **Пропоновані мережі.** Під полем цілей — чипи з мережами, до яких під'єднано
  цей Mac, і їхніми шлюзами (`getifaddrs` + SystemConfiguration, лише читання,
  без трафіку й підпроцесів). Клік лише вписує текст у те саме поле: ціль однаково
  проходить `TargetValidator`, політику й підтвердження області. Точка-точка
  інтерфейси не пропонуються, тож VPN-тунель не стане ціллю в один клік. Мережа
  ширша за /24 звужується до /24 навколо власної адреси й позначається.
* **Валідація цілей.** `TargetValidator` приймає лише IPv4/IPv6/CIDR/діапазони
  октетів/імена хостів із обмеженого набору символів; токени з `-` на початку
  відхиляються, а `--` перед цілями зупиняє розбір опцій Nmap.
* **Allow-list аргументів.** `ArgumentPolicy` дозволяє тільки відомі прапорці й
  перевіряє їхні значення. Прапорці виводу (`-oN`, `-iL`, `--datadir`, …) належать
  програмі й заборонені в шаблонах. NSE — лише безпечні категорії, без шляхів і масок.
* **Підтвердження області.** Перед запуском — sheet із цілями, кількістю адрес,
  очікуваним часом, впливом на мережу, точною командою та явним підтвердженням дозволу.
* **Політика активів.** Цілі поза приватним простором мають збігатися зі списком
  дозволених активів, інакше блокуються. Ризикові інтенсивності — попередження або заборона.
* **Обмеження швидкості.** `--max-rate`, `--max-parallelism`, `--max-hostgroup` і
  ліміт адрес на запуск додає програма; профіль не може їх обійти. `0` = без
  обмеження, прапорець тоді не додається. Дефолт `--max-rate` — 20000 пак/с:
  на звичайній мережі вузьке місце — канал, а не ліміт. Обережно з низькими
  значеннями: 500 пак/с розтягують скан 10000 портів із 0.15 с до 20 с
  (виміряно), тому інтерфейс попереджає, коли саме ліміт визначає тривалість.
* **Аудит.** Append-only JSONL: запит, блокування, старт, завершення, експорт,
  зміни профілів і політики.
* **Дані на диску.** `~/Library/Application Support/Dozor`, каталог 0700, файли 0600.
* **Парсинг XML.** Зовнішні сутності вимкнені (XXE), обрізаний XML після
  переривання зберігається з позначкою.
* **Експорт.** Банери сервісів контролюються сканованим хостом — HTML екранується,
  CSV квотується.

## Що далі

* Планові сканування та сповіщення (моделі під це вже є: `AppPaths.scheduleFile`).
* Root-сканування (SYN/UDP/OS) через привілейований helper замість запуску від root.
* Шифрування збережених результатів ключем із Keychain.
* PDF-звіт напряму (зараз — друк HTML у PDF).
* Перенесення ядра на Linux/Windows або серверний агент.
* Перехід тестів на swift-testing, коли з'явиться Xcode.
